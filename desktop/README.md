# Lele Desktop

Native desktop shell for the [Lele](https://github.com/xilistudios/lele) AI assistant.
Tauri v2 app that bundles the Lele gateway (`lele` sidecar) and web UI into a single
cross-platform desktop app.

## Layout

```
desktop/
├── src-tauri/          # Rust/Cargo crate (tauri)
│   ├── capabilities/   # IPC capability files
│   └── icons/          # Generated app icons
├── splash/             # Static splash page (frontendDist)
└── package.json        # Tauri CLI scripts
```

> `src-tauri/src/*.rs` is generated by the build task — see the project build scripts.

## Prerequisites

- **Rust** toolchain (stable), `cargo` available
- **bun** (or npm) for the Tauri CLI
- **Linux webview deps** (build-time only):

  openSUSE:
  ```sh
  sudo zypper in webkitgtk4-devel gtk3-devel libsoup3-devel
  ```

  Debian/Ubuntu:
  ```sh
  sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
  ```

## Build

The `lele` sidecar binary must exist at `src-tauri/binaries/lele` (built via
`scripts/build-sidecar.sh` — will be added later). Then:

```sh
bun install
bun run tauri build
```

## Notes

- Windows are created programmatically in Rust (splash → main).
- `desktop-remote.json` capability grants IPC to the local gateway origin
  (`http://127.0.0.1:*`) served by the sidecar.
